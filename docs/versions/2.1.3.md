# QuillTeX 2.1.3

2.1.3 增加一键清理中间文件，重新设计 PDF 顶部的编译胶囊，并让后台标签的编译继续运行。

- Folder 侧栏右上新增清除图标，可一键清理当前工程的中间文件；在 Folder、Structure、TeX 侧栏右键文件或文件夹，或在文档标签、文档库文稿的右键菜单中选择 Clear Intermediate Files，也会清理对应的 `.aux`、`.log`、`.toc`、`.bbl`、`.synctex.gz` 等辅助文件。PDF、TeX 源文件和无关的日志不会被删除，清理结果以小提示显示。
- PDF 预览左上角的编译胶囊始终显示，不再因为窗格变窄而消失；内容保持简短：编译中实时显示 `xelatex 1/2`、`bibtex 1/1`、`xelatex 2/2` 这样的第几遍，结束后显示 Build succeeded、warning / error 数量或编译工具缺失。详细错误仍可在悬停提示和 Result 侧栏查看。
- 切换标签不再停止原标签的编译。每个工程拥有独立的编译状态，切到其他标签后原工程继续编译，切回时显示当前的进度、诊断和 PDF；只有关闭最后一个引用该工程的标签或退出应用时才会停止它的编译。
