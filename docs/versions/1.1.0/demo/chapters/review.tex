\section{用一个例子核对计算}
\label{sec:review}
令 $f\equiv 1$，式~\eqref{eq:boundary} 的解为
\[
  u(x)=\frac{x(1-x)}{2}.
\]
它在两个端点取零，且 $-u''=1$。
代入式~\eqref{eq:energy} 可得 $\energy[u]=-1/24$，
与驻值计算一致。

整理文稿时，需要分别核对三个层次：允许函数的边界条件、
一阶变化中的符号，以及弱形式与经典方程之间所需的正则性。
第~\ref{sec:energy} 节和第~\ref{sec:stationary} 节的引用，
把这些检查重新连接到推导本身。
