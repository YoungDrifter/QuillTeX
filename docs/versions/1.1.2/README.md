# QuillTeX 1.1.2

1.1.2 完善插件设置，重新整理 LaTeX 补全的分类与交互。

- 插件提供独立的设置入口、详细使用介绍与开关说明，启用状态与各项设置在重启后保留；Subfiles 可选择显示文件扩展名及未被主文件引用的文件。
- 补全作为默认启用的 Completion 插件，可独立关闭，也可分别配置行内提示、配对符号、结束环境及各类候选。
- 默认按 Option–Esc 打开候选列表，可在 Completion 设置中录入自定义快捷键或恢复默认，菜单同步更新；继续输入筛选，方向键选择，Return／Tab 或鼠标点击确认，Esc 关闭；支持命令、环境、宏包、文档类、标签、文献键及工程内文件路径。
- 环境分阶段补全：先接受 `\begin{}`，再选择环境名，最后按 Tab 插入正文空行与对应 `\end{…}`，每一步均可单独撤销；结束环境预览使用实际换行，中间保留空行，下方已有正文时灰色提示仍保持可见，确认前不改动源码。
- 优先匹配工程自定义命令与环境，复用已有括号和参数，避免重复插入结束环境；括号与数学定界符保留行内提示，不混入候选列表。
- 候选列表沿用应用统一的圆角、轻描边与选中反馈，支持滚动并限制在屏幕可用范围，保持编辑器输入焦点；关闭插件立即撤销提示和候选、停止补全任务并移除菜单入口。
- 文件右键弹窗按完整操作文字自适应宽度，避免菜单名称被截断；统一按钮按下反馈与弹窗列表的连续圆角、选中背景过渡，保持原有工作区布局。

演示和界面素材沿用 [1.1.0](../1.1.0/README.md)。
