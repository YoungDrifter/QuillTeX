# QuillTeX 2.0.2

2.0.2 保持窗格与缩放状态，并修复标签栏细节。

- 打开文件或切换标签不再自动改变编辑 / PDF 窗格；重新打开工作区会恢复上次的窗格模式。
- 点击 Editor + PDF 会把两栏重新对齐为等宽；已经等宽时不会反复微调。
- PDF 顶栏保留 Actual Size（真正的 100%）与 Fit Width，并新增 Fit Height 按页高适配；缩放按钮保留图标并带悬停提示。
- 修复从 New Tab 页切换到主页或其它标签时，标签胶囊被压成细线再消失的问题；暂态 New Tab 与其它标签使用相同的淡出效果。
- 重命名按位置区分：标签与文件库侧栏的 Rename Project 改显示名、Rename Main File 改磁盘主文件名（对话框标题也为 Rename Main File）；编辑区左上角的 Rename 修改磁盘文件名；项目侧栏 TeX / Folder 页右键 Rename 也改磁盘文件名；Structure / Result 是只读导航，不提供重命名。File 菜单也提供 Rename…（⌘⇧R）。默认显示名会跟随新文件名，自定义显示名保持不变。
- 补全不需要配置：行内提示、配对、环境结束与所有候选分类始终全部开启，Esc 打开候选，候选列表内 Esc 关闭；设置保留 Compilation 与 About：About 提供版本、GitHub 地址和检查更新；Automation 合并到 Compilation；Subfiles 始终只显示文件名。
- Completion 与 TeX Project 不再是可选插件，始终启用，相关源码移入 Editor/Completion 与 Project/Subfiles。
