# QuillTeX 1.0.3

本版优化编辑、编译诊断、工作状态恢复与 PDF 校对体验。

- 修正带冒号、下划线等字符的标签和引用键补全，支持多个引用键；区分开始与结束环境，避免重复插入括号和环境尾部。
- 常用数学命令可补齐参数，使用 Tab／Shift-Tab 在参数间移动；补全识别工程中声明的命令、定理与环境。
- 将语法扫描和补全分析移到后台，缓存未修改文件的工程分析，减少长文稿编辑时的重复工作。
- 编译前检查当前引擎和策略所需的工具；显示当前编译步骤和实时日志，可从 Compile 菜单停止编译。
- 编译问题按错误和警告分组，支持分类筛选和前后跳转，源码行号旁显示问题标记；常见错误提供简短检查建议。
- 排版校对集中显示溢出行、未解析引用和重复标签；正确报告 BibTeX／Biber 的处理失败。
- 按工程恢复文件标签、完整选区、滚动位置、面板布局和 PDF 阅读位置；异常退出后的未保存编辑可恢复，正常丢弃的编辑不会重新出现。
- 双向定位在后台执行，失败时说明原因；源码与 PDF 中短暂标亮目标行或区域，并提示当前显示的 PDF 是否等待重新编译。

这些改进均属于基础功能，无需启用插件。
