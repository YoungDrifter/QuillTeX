# QuillTeX 1.1.3

1.1.3 重新整理多文件 TeX 文稿的关系管理，并精简工作区界面。

- 原 Subfiles 插件更名为 TeX Project，侧栏按 Main、Sub、Others 展示 TeX 文件，其中 Sub 由文件自身的 `% !TeX root = …` 注释确定，Others 收纳未指向当前 Main 的文件。
- 文件可拖到 Main、Sub 或 Others，分别切换工程入口、添加或更新主文件注释、移除主文件注释，修改直接进入文稿的正常编辑与恢复流程。
- 关闭 TeX Project 后不再固定工程主文件，打开没有主文件注释的 TeX 文件时直接以该文件作为编译与预览目标，文件已有主文件注释时仍打开其声明的目标。
- 移除自定义标签栏及相关按钮、菜单和恢复状态，文件切换统一通过 TeX、Folder、Structure 侧栏与编辑区路径完成，前进与后退导航移到侧栏顶部右侧。
- 侧栏改为贯穿窗口全高并使用独立浅灰色调，侧栏按钮紧邻窗口控制键且全屏时靠左；原顶栏仅保留为右侧内容区顶栏，并收紧为更轻的 46 pt 高度，侧栏与顶栏按钮统一为 32 pt；前进与后退在侧栏展开时位于侧栏右端，收起侧栏后与“显示侧栏”按钮并入右侧顶栏左端；编辑区与 PDF 预览区顶栏改为内容自适应的悬浮胶囊，内容可从胶囊下方滚动；整个右侧内容区保持不透明纯白，顶栏与下方内容之间增加细分隔线。
- 内容顶栏把编译胶囊移到文件名左侧，文件名在剩余空间居中；侧栏与启动页左栏使用 behind-window 模糊材质和白色覆盖层，只保留轻微背景色而不透出文字，窗口分隔线改为实色绘制。
- 拖拽侧栏分隔线到最左侧收起时，顶栏立即同步为收起布局，显示侧栏、前进后退与编译胶囊不再遮挡窗口控制键。
- 编辑区与 PDF 预览区顶部保留 54 pt 纯白缓冲留白，留白随正文滚走，滚动后胶囊之间可直接显示内容，预览滚动条轨道从面板顶部开始；保留到顶后的弹性回弹。
- 单个编译步骤超过 10 分钟会结束并给出超时错误，避免编译长期停留在进行中状态。
- 顶栏空白区域支持系统“双击标题栏”动作：缩放、最小化或按系统设置为不操作；单击空白仍可拖动窗口，按钮与胶囊槽位不会误触发缩放。
- 移除 PDF 预览顶部固定的细白条和中间编译状态胶囊，状态统一从顶栏与 Result 侧栏查看；切换单栏、分栏或仅 PDF 模式，以及重新编译时保持阅读位置。
- 打开文件的默认窗口调整为 1280 × 760，默认侧栏 248 pt，编辑区与预览区等宽；编辑区滚动条与分隔线抓取区重叠时优先响应滚动条，分隔线仍可从预览一侧拖动。

演示和界面素材沿用 [1.1.0](../1.1.0/README.md)。
