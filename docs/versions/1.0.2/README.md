# QuillTeX 1.0.2

本版统一界面视觉，并补齐顶栏的最近项目入口。

- 统一顶栏、标签栏、侧栏、补全框、编译面板与设置的颜色、圆角与描边：图标按钮使用一致的圆形点击与高亮区域，胶囊与浮层共用浅色表面和细描边，不再叠自定义浮层阴影。
- 顶栏新增历史记录按钮，打开最近项目列表即可切换项目；列表支持逐条删除与一次清空。
- 历史记录与编译引擎改用与其他弹出菜单一致的系统 popover；所有弹出列表共用同一套行样式（图标、标题、路径与悬停底色）。
- 启动页的最近记录去掉右键菜单，删除改为悬停时显示。
- 打开文稿的入口改用居中的加号图标；分栏按钮的填充位置调整到右侧，与“仅 PDF”的整块填充一致。
- 修复连续点击顶栏按钮边缘时误触发窗口放大的问题。
