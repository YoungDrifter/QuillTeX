# QuillTeX 2.0.1

2.0.1 完善文档库与结构导航，并补上轻量反馈。

- 文件夹右键新增 Sort By（Manual / Name / Kind / Last Viewed / Date Created / Date Updated），选择会持久保存；拖动文档后自动切为 Manual 并记住顺序。
- Structure 目录跳转时在编辑区落点显示与 PDF → 源码同步一致的灰色行高亮；跳转只影响当前打开的窗格，不再自动切换编辑 / PDF 模式。
- PDF 导出成功、移动文稿到废纸篓、从文档库移除、打开文档时显示底部玻璃小提示，约 1.7 秒自动消失；需要输入或确认的弹窗保持原样。
- 文档标签右键可 Export PDF…。
- 编辑区插入光标高度改为贴合字形，不再包含整行行距。
- Structure 目录读取编译生成的 `.toc`，任何写入目录的自定义环境（例如 academic_exercise 的第 N 题）都会显示，同时保留尚未编译的新标题。
