# QuillTeX 2.1.2

2.1.2 修正 TeX root 注释的写入范围，并让主文件实际引入的 TeX 文件自动成为子文件。

- 打开文稿时只给主文件补上 `% !TeX root` 注释，不再给目录下的每一个 TeX 文件写入注释；其他文件仍可在 TeX Project 侧栏拖动到 Sub 手动添加，拖到 Others 移除。
- 主文件通过 `\input`、`\include`、`\subfile` 以及 import 系列命令实际引入的 TeX 文件，会自动作为子文件并补上指向主文件的 root 注释；子文件继续引入的文件也包含在内。
- 编辑主文件或已引入的子文件时，手动敲入新的引入命令，短暂停顿后会自动把目标 TeX 文件提升为子文件并补注释，不必重新打开工程。
- 导入文件夹时只根据 root 注释识别主文件：没有 root 注释指向的文件不会导入；找不到主文件时提示 No Main File Found。
- 子文件指向的主文件即使自身还没有 root 注释，也会被正常打开并补上；重命名主文件只更新真正指向它的 root 注释，不会改动同一目录中无关工程的注释。
