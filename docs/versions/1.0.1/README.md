# QuillTeX 1.0.1

本版优化侧栏、补全与编辑交互，并调整编译设置和 About 版本信息。

- 初次打开工程时，Structure、Folder 与 Subfiles 中的所有可展开层级默认折叠；手动展开后，在编辑和切换侧栏分类时保留状态。
- 扩大展开箭头的点击区域；结构分组与文件夹支持整行点击展开或收起。
- 展开与收起时平滑调整子项高度，并同步转动箭头。
- About 显示当前版本和最新版本的内部构建号，便于区分同版本更新；打开 About 时刷新最新版本信息。
- 补全提示框限制尺寸与屏幕边界，较长候选列表在框内滚动；支持鼠标悬停反馈与点击选择。
- 修复 ⌘Z 撤销，支持 ⇧⌘Z 重做；编辑区顶部增加撤销与重做按钮，Edit 菜单同步提供对应操作。
- 设置增加 Manual 模式下保存后编译选项，默认关闭；开启后，Save 和 Save All 保存成功会编译主文件。
