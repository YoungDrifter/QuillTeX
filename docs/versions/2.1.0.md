# QuillTeX 2.1.0

2.1.0 修复多标签、重命名与编译收尾的边界问题，并细化文档库在窄窗口下的布局。

- 同一文件夹中的不同主文件现在各自保持独立的工程标签与编译目标；切换标签不会再复用另一个工程的编辑缓冲区，两个工程也不会互相改写主文件注释或误报外部修改。
- 重命名主文件时，标签、文档库位置、历史记录与窗口标题同步到新路径，自定义项目显示名保持不变。
- 关闭标签会检查该工程的全部未保存子文件，以及后台标签保留的未保存草稿；确认丢弃后才清除对应恢复数据，取消关闭不会影响标签。
- 文档标签的 Export PDF 使用该标签所属工程的编译结果；设置输出目录后，导出与编译读取同一位置，不再误用当前窗口或旁边残留的旧 PDF。
- 取消编译或编译超时会结束整个 LaTeX 进程组，避免后台引擎继续写入；没有标准源码定位的失败也会在 Result 中说明出错的工具与退出码。
- 文档库排序箭头与实际顺序一致：选择 Name / Last Viewed / Created 等字段时采用该字段的自然方向，再次点击切换升降序，日期分组随方向一同反转。
- 文档库窄窗口下自动收起文档数量、隐藏次要日期列并收窄搜索框；标签过多时自动把当前标签滚入可见区域，缩放窗口后仍保持可见。
- PDF 百分比输入在编辑期间不再被延迟的缩放回调覆盖；设置页内容宽度和弹窗焦点交接也一并收紧。
- 文档库侧栏的文件夹展开与收起统一为同一个高度折叠动画：顶层文件夹与子文件夹不再一个瞬间出现／消失、一个平滑滑动；收起时先裁切内容再移除，下方行平滑归位。
- 修复从文档库打开文稿、或关闭标签后重新打开时，编辑区与 PDF 的分隔线偏左约 8 pt、再点 Editor + PDF 才回正的问题；现在打开文稿会直接保持编辑区与预览区等宽。
