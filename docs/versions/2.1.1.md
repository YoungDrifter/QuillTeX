# QuillTeX 2.1.1

2.1.1 调整标签的打开方式，完善文档库文件夹的导入入口，并支持一次导入整个文件夹。

- 未显式新建标签时，打开文稿或文件夹会在当前标签内切换，不再不断新增标签；再次打开已经在其他标签中打开的文稿时会回到那个标签。
- All Documents、Starred 与 Templates 共用主页标签：点击这些入口只切换主页当前显示的视图，不新增标签；离开主页后点击 home 图标，会回到上一次查看的视图。
- 点击加号仍然新建标签。文稿、文件夹、模板以及 All Documents、Starred、Templates 的右键菜单都提供 Open in New Tab，同一个文稿、文件夹或主页视图可以同时存在于多个标签。
- 文档库文件夹右键的 Open Documents 改为 Open Documents to This Folder…：从本地选择文件或文件夹，加入文档库并移入该文件夹后直接打开，与 New Document in This Folder 对应。
- 选择文件夹时会递归导入其中的主文档；同一工程的 subfiles 跟随其主文档，只计为一个文稿，不会重复导入。隐藏文件、`build` 与 `node_modules` 会被跳过。文件夹中只有一个主文档时直接打开；有多个主文档时只导入并提示，不自动打开任何一个。
- 修复在 Open Documents to This Folder… 中选择文件夹时 Open 按钮不可用的问题；现在文件和文件夹都可以选中。
- 文档库侧栏会记住文件夹的展开／收起状态；返回主页或重启应用后恢复上一次的状态，不再重置为全部展开。
- 修复按 Added 列排序时 Sort By 菜单没有勾选项的问题；菜单现在包含 Date Added，并且始终保留当前排序项。
- 文件夹右键同时提供 Open in New Tab；New Folder、Export PDFs、Sort By、重命名与删除等原有操作保持不变。
