# QuillTeX 2.0.0

2.0.0 以本地文档库和标签化工作区重做写作入口，把文稿整理、编辑、编译与 PDF 预览放在同一个窗口。

- 本地文档库自动收录打开的 `.tex`，可按文件夹、Star 和搜索整理；文件夹可自定义颜色，新建时选择或通过右键菜单修改；提供列表与 PDF 卡片视图，支持日期属性与排序方向切换，并记住上次的视图模式。
- All Documents、Starred、Templates 和文件夹都以标签打开；All Documents 是临时主页标签，打开文档后折叠回 home 图标，点击即可回到文档库。
- 标签支持拖动排序与关闭；关闭最后一个标签会打开 New Tab 页面，提供新建、打开、模板、Quick Open 与最近文档。
- Templates 以卡片或列表呈现每个模板的 `.tex` 内容与日期；可在应用内新建、编辑、重命名和删除模板，点击模板即可像普通文稿一样编辑，不显示 PDF 预览和编译按钮。
- 新建文档弹窗包含名称、位置与模板三项，默认保存到 `~/Documents/QuillTeX`，并记住上次使用的文件夹；默认新建位置可在设置 → Library 中修改；模板选择 None 时创建空白文稿。
- 新建文档、文件夹与确认弹窗统一为简洁的浮动卡片样式：标题、关闭按钮、字段与全宽主操作。
- 文稿列表显示 Last Viewed、Added、Updated、Created 四项日期属性，并在名称下方显示所在文件夹路径；再次点击当前排序可切换升降序。
- 文稿和文件夹右键可把已编译 PDF 导出到指定目录；文件夹右键还支持新建、打开、重命名与删除。
- 设置以标签打开，侧栏第 2 页显示编译配置、自动构建与 Library 分类，以及应用图标、名称与版本；检查更新保留在应用菜单。
- Completion 与 TeX Project 已成为内置功能，无需单独启用。
- 统一按钮、胶囊、标签和卡片的玻璃材质与悬浮反馈，并优化标签增删、侧栏翻页、设置页和文稿库的动画。
