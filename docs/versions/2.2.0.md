# QuillTeX 2.2.0

2.2.0 增加坚果云 WebDAV 单向同步：把编译好的 PDF 和文稿库信息上传到云端，供另一个只读应用接收。

- 顶栏最右侧新增同步按钮，手动触发，不会在编译或保存后自动上传。鼠标悬停可看到上次同步时间。
- Settings 新增 Sync 分类，可填写账号、应用密码和远端文件夹；WebDAV 服务器固定为坚果云地址。应用密码保存在系统钥匙串，不写入偏好或同步状态文件。
- 单向发布：QuillTeX 只上传，不读取或合并云端修改。另一个应用只读 `index.json` 和 PDF，不会反向修改文稿库。
- 增量同步：只有新增、内容变化或元数据变化的内容才会上传。PDF 按内容哈希命名，未变化的 PDF 不会重复传输；`lastViewedAt` 这类易变字段不会单独触发整份索引重传。
- 上传内容包括：编译后的 PDF、文稿库文件夹结构、文稿名称、标签、星标、日期，以及主文件名等项目信息。TeX 源码、图片和参考文献仍只保存在本机。
- 远端只保留当前版本：新索引上传成功后，旧 PDF blob 会被清理，避免同步目录随每次编译不断增长。
- 接收端的目录结构和 JSON 字段说明见 [WebDAV 同步协议](../webdav-sync.md)。

坚果云 WebDAV 的单文件上限为 500 MB；免费账号限制为每 30 分钟 600 次请求，付费账号为 1500 次。同步按“一个索引 + 变化的 PDF”组织，正常使用不会接近请求上限。
