# QuillTeX 1.1.1

1.1.1 优化输入响应，调整补全、侧栏与 PDF 工具栏的交互。

- 空白模板不再预置任何 LaTeX 内容；内置模板文件统一为英文名称，去掉 `basic_` 前缀，已有模板迁移时保留自定义内容，重名副本以编号区分。
- 减少连续输入和光标移动时的重复处理，改善长文稿编辑响应；回车延续当前缩进并保留原换行格式。
- 括号与结束环境先显示灰色提示，按 Tab 接受，避免键入时直接插入补全内容。
- 修正窗口红黄绿按钮的悬停区域偏移，Folder 中的文件夹排在文件前面。
- Subfiles 可在 Settings → Plugins 中独立开关，默认开启；关闭后移除入口并取消相关拖动操作，保留源文件与基础导航功能，重启后恢复开关选择。
- 侧栏胶囊随可用模式数量整体调整宽度和排列，三项与四项均保持居中、均匀间距及滑动选中态。
- PDF 顶栏将可编辑百分比、Actual Size 和 Fit Width 合为右侧一个胶囊，左侧显示 PDF 标识、中间显示编译信息，移除待编译提示条。
- 精简权限、文件冲突、模板和历史记录等弹窗说明，保留必要的操作后果；保存失败后不再重复弹出编译错误提示。

演示和界面素材来自 [1.1.0](../1.1.0/README.md)。
